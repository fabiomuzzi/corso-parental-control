# Parental control in famiglia: la guida pratica

**Leggi la guida: https://fabiomuzzi.github.io/corso-parental-control/**

Sono Fabio Muzzi, papà e professionista del digitale. Ho scritto questa guida per accompagnare i genitori, un passo alla volta, a proteggere la rete di casa, gli smartphone e le SIM dei figli. Non serve essere esperti: ogni modulo richiede 15-30 minuti, ha i passi numerati e una breve verifica finale.

La guida è gratuita e senza pubblicità. Questo repository contiene tutti i testi: qui puoi seguire gli aggiornamenti e segnalarmi errori o passaggi poco chiari.

## Hai trovato un errore o un passaggio cambiato?

Telefoni, app e menu cambiano spesso. Se un passaggio non corrisponde più a quello che vedi sul tuo dispositivo, [apri una segnalazione](https://github.com/fabiomuzzi/corso-parental-control/issues/new) indicando il modulo, il modello del dispositivo e la versione del sistema (per esempio "iPhone 15, iOS 27.1"). Ogni modulo riporta la data e le versioni su cui l'ho verificato.

## Come è fatta

- Le pagine sono file Markdown nella cartella `docs/`, una per modulo; gli screenshot sono in `docs/img/modulo-N/`.
- Il sito è generato con [Zensical](https://zensical.org/) e pubblicato con GitHub Pages a ogni modifica del ramo `main` (`.github/workflows/pubblica.yml`).
- Font ospitati nel sito, senza servizi esterni: Atkinson Hyperlegible Next e Nunito, entrambi con licenza SIL Open Font License (vedi `docs/fonts/`).
- L'immagine di apertura è generata con l'intelligenza artificiale ed è segnalata come tale. Gli screenshot delle app sono reali, fatti sui miei dispositivi.

Per vedere il sito sul tuo computer:

```
pip install zensical
zensical serve
```
