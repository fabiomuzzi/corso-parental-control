# Parental control in famiglia: la guida pratica

Guida passo per passo per genitori: il patto in famiglia, i filtri DNS sulla rete di casa, la SIM, gli smartphone (iPhone e Android), console e social.

Scritta da [Fabio Muzzi](https://www.fabiomuzzi.com/). Il sito è generato con [Zensical](https://zensical.org/) e pubblicato con GitHub Pages a ogni modifica del ramo `main`.

## Struttura
- `docs/`: le pagine della guida in Markdown, una per modulo.
- `docs/img/modulo-N/`: gli screenshot.
- `zensical.toml`: configurazione (menu, tema, colori).
- `.github/workflows/pubblica.yml`: pubblicazione automatica.

## Provare in locale
```
pip install zensical
zensical serve
```
